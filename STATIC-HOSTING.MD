## Хостинг сайтов игр
### Общее описание

Сайты игр хостятся с использованием статического хостинга S3 в Яндексе. 


### Что сделать

1. Создать в Object Storage бакет для сайта. Он должен называться строго по имени будущего домена
1. Добавить права на заливку сервисному аккаунту ХХХХ-ci-uploader
1. Пойти в identity & access management в облаке, создать там новый IAM ключ и положить его в  secrets.SYNC_ACCESS_ID / secrets.SYNC_ACCESS_SECRET
2. Скопировать скрипт автоматической публикации — пример тут  https://github.com/leotsarev/leotsarev.ru/blob/master/.github/workflows/main.yml
3. Выполнить его в первый раз
3. Включить хостинг в настройках бакета
4. Привязать внешний домен через Cloud DNS (в настройках бакета). При необходимости сделать тоже самое с www
5. Пойти в Certificate manager, добавить там Let's Encrypt сертификат для домена. Пойти в настройки сертификата, в разделе «проверка прав» указать «создать запись».
6. После того, как сертификат создатся, Бакет → Безопасность → HTTPS указать сертификат
7. Ждать пока все просрется

### Переход с тильды

1. Скачать с тильды архивом экспорт
2. Обработать тулзой
